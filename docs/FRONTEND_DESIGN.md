# 🎨 Frontend Design System & Tokens

## 1. Color Palette Tokens
- **Primary Accent**: Sky Blue (`sky-500` / `#0ea5e9`)
- **Backgrounds**: Slate Dark Mode (`slate-900` / `slate-950`) & Light Theme (`slate-50`)
- **Cards & Glassmorphism**: `bg-white/80` or `bg-slate-900/80` with `backdrop-blur-md`
- **Badges**:
  - `Won` / `Low Risk`: Emerald (`emerald-500`)
  - `Proposal` / `Medium Risk`: Amber (`amber-500`)
  - `Lost` / `High Risk`: Rose (`rose-500`)

## 2. Typography & Icons
- Font Family: Inter / System Sans
- Icons: `lucide-react` vector icon suite.
