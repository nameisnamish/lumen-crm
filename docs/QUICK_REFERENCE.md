# ⚡ Quick Reference & Cheatsheet

## Common Commands
| Action | Directory | Command |
| :--- | :--- | :--- |
| **Start Frontend** | `cd frontend` | `npm run dev` |
| **Run Unit Tests** | `cd frontend` | `npm run test` |
| **Start Backend API** | `cd backend` | `node server.js` |
| **Production Build** | `cd frontend` | `npm run build` |

## Key File Paths
- **Frontend App Routes**: `frontend/src/App.jsx`
- **Axios API Client**: `frontend/src/lib/api.js`
- **Backend Express App**: `backend/server.js`
- **Gemini AI Service**: `backend/src/services/geminiService.js`
- **Global Auth Context**: `frontend/src/context/AuthContext.jsx`
